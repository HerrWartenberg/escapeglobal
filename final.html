Das Schlüsselwort

Eure Recherche dreht sich um verschwundene Container­ware. Bildet aus den Anfangsbuchstaben der fünf Stationsthemen ein einzelnes Wort:

Welthandel
Akteure (Konzerne)
Rohstoffe & Wertschöpfung
Entwicklungsfolgen (Gewinner/Verlierer)
Nachhaltigkeit

→ Das Schlüsselwort: Schreibt es auf einen Zettel, ihr braucht es gleich.

Die Berechnung des Türcodes

Berechnet drei Zahlen und setzt sie zusammen:

  1. Anzahl der Buchstaben des Schlüsselworts → Zahl A
  2. Quersumme von Code 1 (3+2+1+4) → Zahl B
  3. Anzahl der „G" in Code 4 (GVGV) → Zahl C

Setzt die drei Zahlen direkt hintereinander zusammen: A B C ergibt einen 4-stelligen Türcode (Zahl B ist zweistellig!).

Hinweis 1 öffnen
Das Schlüsselwort hat 5 Buchstaben. Beginnt mit „W", endet auf „N".
Hinweis 2 öffnen
Zahl A = 5 (Buchstaben des Wortes WAREN). Zahl B = 3+2+1+4 = 10. Zahl C = wie oft kommt G in GVGV vor?
Hinweis 3 öffnen (fast Lösung)
A=5, B=10, C=2. Hintereinander: 5-10-2 → ohne Bindestriche: 5102. Das ist euer Türcode.
